# iOS

A signed iOS IPA / App Store build is **not produced here**.

iOS installers need:

- a Mac
- Xcode
- an Apple Developer account and signing certificates

This builder and GitHub’s Linux runners cannot sign an IPA that a normal iPhone will install.

The working phone app for now is the Android sideload APK from [Releases](https://github.com/l3g1Xn/lexiforge-ai-chat/releases).
